# photonic-neural-comp
Documentation for the Photonic Neural Computing project.

Code for thesis results:
- training_inference.ipynb: ONN simulations (first half of the project)
- calibration.ipynb: Phase error estimation experiments, SVD mesh simulation, multi-core emulation (second half of the project)

Others:
- thesis.pdf: The final thesis that was submitted and graded
- inference_draft.ipynb: Draft notebook for playing around with Neurophox
- doc: Contains documentation made throughout the project 
- Lit.bib: BibTeX file containing updated references and citations (OUTDATED)
- README.md
